# Continuity and control

Continuity defines what the current clip inherits and what the next clip receives. Control defines which relationships are too important to leave ambiguous during execution.

## Evidence hierarchy

Keep these sources distinct:

- locked story facts define what is true in the narrative;
- project creative grammar defines recurring presentation rules;
- inspected visual/audio evidence defines the actual visible or audible state of an existing take;
- directorial decisions define the planned state of the current clip.

For a continuing physical moment, inspected evidence outranks assumptions about the predecessor's visible state. If it conflicts with a locked fact, report the conflict rather than rewriting either source.

## Continuity in

Record only inherited state that affects the shot:

- character identity, position, orientation, eyeline, posture, and active behavior;
- location geometry, time, weather, lighting direction, and active environmental motion;
- prop ownership, count, placement, condition, and ongoing movement;
- screen direction and relevant camera relationship;
- dialogue, ambience, music, or sound already in progress;
- literal opening composition only when the existing composition must continue.

Do not force continuity across an intentional change of time, place, perspective, style, or montage unit.

## Continuity out

Define the exact consequential state the next clip may inherit:

- final subject positions and orientations;
- gaze, posture, expression, and unfinished movement;
- prop ownership and object state;
- environment, light, weather, or time progression;
- final composition when it matters;
- speech endpoint, effect decay, ambience, music, or silence.

The outgoing state is a **plan** until rendered output is reviewed. The accepted take becomes the factual visual evidence for the next clip.

## Handoff types

Useful handoffs include:

- **continuous action** — movement continues across the boundary;
- **settled state** — the first clip ends stable so the next can begin cleanly;
- **eyeline / point-of-view** — attention transfers to what a subject sees;
- **sound bridge** — audible continuity connects different views or moments;
- **graphic/motion relationship** — similar shape or movement creates the connection;
- **deliberate discontinuity** — the break itself is intentional and should not be repaired.

## Precision versus latitude

Explicitly distinguish:

### Must remain exact

Use for facts or relationships whose variation would break meaning or continuity:

- exact dialogue;
- cast count or identity when story-critical;
- object ownership;
- entrance/exit direction;
- a required spatial relationship;
- a specific reveal order;
- a hard timing cue;
- a required opening or ending state.

### May vary

Use for details whose variation does not change the shot's meaning:

- incidental micro-gestures;
- small environmental motion;
- minor texture variation;
- nonessential background activity;
- subtle camera breathing when the project grammar allows it.

Do not over-lock the scene. Precision is valuable only where variation has a cost.

## Control / previs dependencies

Sometimes a semantic contract is not enough. Surface a control dependency when execution would otherwise have to guess a load-bearing relationship.

Examples:

- opening geometry must be visually anchored;
- the final silhouette/pose must be predetermined;
- hand-to-object contact needs a clear key pose;
- screen direction must be shown in a spatial diagram;
- dialogue timing must be checked against an existing recording;
- a complex transformation needs start/end visual states;
- interface motion needs an approved still/layout before animation.

State **what must be anchored**, not how a particular provider should anchor it. Asset creation and provider-specific control mechanisms belong downstream.

## Control is not decoration

Do not request a storyboard, keyframe, diagram, or reference merely because one could exist. Require extra control only when it reduces meaningful ambiguity, protects continuity, or prevents an expensive execution from guessing a critical relationship.

## Conflict handling

If locked facts, inspected evidence, duration, or spatial constraints cannot all coexist:

1. preserve locked story facts;
2. preserve observed state when continuity is required;
3. simplify discretionary direction;
4. report the unresolved conflict if it still remains.

Do not hide the conflict inside a vague prompt or an impossible camera plan.
