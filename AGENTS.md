# Pipeline routing

Choose the owning pipeline and read its `README.md` and `AGENTS.md` before changing or running a production. `pipelines/image-story` owns narrated illustration/mixed-media stories; `pipelines/generated-video` owns generated clips and hash-bound review/assembly. Keep their environments, scene contracts, runtime state, and creative skills separate. Use the root `docs/` for shared setup, licensing, provenance, and validation scope.
