# Workspace Scope
This project hosts both the rendering pipeline codebase (`src/`) and the agentic creative skills (`.agents/skills/`). Do not confuse codebase maintenance tasks with video content generation runs.

# Workspace Rules (Codebase Maintenance Only)

* **Code Changes**: Do not modify `src/`, `tests/` or `.agents/` without prior plan approval.
* **Planning**: Do not start coding when asked only to document approaches (e.g., in `todo.md`).
* **Commits**: Ask user to verify changes, then git commit with a descriptive message.
* **Project Focus**: Work strictly on the target project specified by the user; never launch background tasks or renders for unrequested projects.
* **Pipeline Settings**: Do not alter render presets, encoding options, or core pipeline parameters without explicit user instructions.
* **Only do whatever you are told to**: Do not try to overstep, this project is sensitive. Only do what you have been told to, if you have been asked something as reflection answer that and don't jump on coding it quickly.
