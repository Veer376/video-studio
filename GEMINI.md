# Workspace Scope
This project hosts both the rendering pipeline codebase (`src/`) and the agentic creative skills (`.agents/skills/`). Do not confuse codebase maintenance tasks with video content generation runs.

# Workspace Rules (Codebase Maintenance Only)

* **Code Changes**: Do not modify `src/`, `tests/` or `.agents/` without prior plan approval.
* **Planning**: Do not start coding when asked only to document approaches (e.g., in `todo.md`).
* **Commits**: Ask user to verify changes, then git commit with a descriptive message.
