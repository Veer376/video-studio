# Trusted Sources

This file is maintained by the `content-creator` skill. It records sources that have consistently produced high-quality, emotionally resonant material for motivational and spiritual story videos. The agent updates this file after each video when a source yields particularly strong material.

## Spiritual & Philosophical Sources

| Source | Type | Best For | URL |
|---|---|---|---|
| Swami Vivekananda Complete Works | Text archive | Courage, self-belief, spiritual seeking | https://www.ramakrishnavivekananda.info/vivekananda/complete_works.htm |
| Bhagavad Gita (Wisdom Library) | Shloka reference | Dharma, action without attachment, karma | https://www.wisdomlib.org/hinduism/book/shrimad-bhagavad-gita |
| Mahabharata Stories | Narrative source | Complex characters, moral dilemmas, sacrifice | https://www.wisdomlib.org/hinduism/book/mahabharata |
| Upanishad Texts | Philosophical | Deep questions, self-realization, consciousness | https://www.sacred-texts.com/hin/upan/ |

**Effective search queries for this category:**
- `"Vivekananda story" perseverance site:ramakrishnavivekananda.info`
- `"Bhagavad Gita" lesson "never give up"`
- `Mahabharata character lesson "{theme}"`

## Web Search Patterns That Work

Use these search strategies in Phase 1 (Discovery) for strong results:

```
1. Spiritual angle:    "{theme}" Vivekananda OR Krishna OR Gita story lesson
2. Real story angle:   "true story" India "{theme}" site:thebetterindia.com OR site:humansbombay.com
3. Universal angle:    "{theme}" "life lesson" story emotional
4. Historical angle:   historical example "{theme}" India ancient
5. Contrast hook:      "{theme}" paradox OR contradiction surprising truth
```

---

## Sources to Avoid

- Wikipedia (too encyclopedic, lacks narrative warmth)
- Quora answers (anecdotal, unverified)
- Generic motivational blogs with no authorship
