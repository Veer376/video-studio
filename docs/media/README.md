# Showcase media

`video-studio-showcase.mp4` is a 48-second, 1080p H.264/AAC overview. `video-studio-poster.png` is a frame from its rendering explanation.

The repository README uses a GitHub-uploaded copy of the same video for native inline playback. The committed MP4 remains available with the source checkout.

Footage and illustrations come from Aryaveer's own KathaMind Hindi production, **Koi Tumhe Seriously Nahi Leta**, with creator permission. See [KathaMind Hindi](https://www.youtube.com/@KathaMindHindi). Motion graphics and electronic sound accents were authored for this overview. Source narration is muted.

Process graphics illustrate the workflows; they are not software screen recordings. The review gate illustrates an approval decision, not a historical approval record for the displayed clip. The generated-video assembly graphic divides one existing clip into editorial segments. Its final proof is labelled “Generated clip output”; it does not claim a separately validated full production from that pipeline. Timeline playback is compressed for explanation, not a performance benchmark. No new paid generation or current-model validation was performed for the film.
